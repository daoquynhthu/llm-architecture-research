# Minimal Transformer

A local minimal implementation target for dense decoder-only Transformer architecture experiments.

Planned components:

- token embedding;
- RMSNorm;
- RoPE;
- causal self-attention;
- MHA/GQA switch;
- SwiGLU FFN;
- KV-cache interface;
- small synthetic tests.

This directory is for clean-room code written for this repository, not copied upstream model code.
